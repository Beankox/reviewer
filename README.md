# Law 101 Reviewer: Obligations and Contracts

A static study page. No build step.

## Files

- `index.html`, `style.css`, `script.js`, `quiz.js`, `reviewer.js`: the page, quiz and reviewer text
- `reviewer.js`: the reviewer text, embedded (no extra file needed). Optional: a full `reviewer.md` next to `index.html` replaces it.

## Run it

- GitHub Pages: push all the files to a repo, then Settings > Pages > Deploy from a branch > `main` / root.
- Locally: run `python3 -m http.server` in this folder and open http://localhost:8000, or just open `index.html`.

## Features

Sidebar contents with scroll tracking, search by topic, a 23-question practice quiz (explains the right answer when you miss one and links back to the topic), light and dark themes, tagged article citations, and print styles (one part per page).
